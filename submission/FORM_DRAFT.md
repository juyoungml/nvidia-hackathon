# 온라인 신청서 초안

서비스명: **Plant Reliability Agent** (가칭)
팀명: 제출 전 입력 필요
팀원: 2~5인 구성 및 각 구성원의 개별 신청 확인 필요

## 해결하고자 했던 문제 — 300자 내외

발전소나 열공급 설비에 이상 신고가 들어오면, 엔지니어는 원인을 따지기 전에 자료부터 뒤집니다. 계측 추세, 과거 신고, 정비 이력을 하나씩 대조하는 데 시간이 많이 듭니다. 더 어려운 건 계측이 정상처럼 보일 때입니다. 공급온도가 설정값을 잘 따라가도 고객은 난방이 안 된다고 할 수 있고, 이때는 데이터에 없는 실내 온도나 2차측 유량을 확인해야 한다는 판단이 필요합니다. 저희는 이 첫 조사를 에이전트가 대신 해 두는 서비스를 만들었습니다.

## 서비스 소개 및 주요 기능 — 500자 내외

Plant Reliability Agent는 설비 이상 신고를 받으면 관련 자료를 스스로 골라 읽고, 다음에 무엇을 확인해야 하는지 근거와 함께 엔지니어에게 넘겨줍니다. NVIDIA Nemotron 3 Ultra가 계측, 과거 신고, 정비 이력, 특정 시간대 조회 등 읽기 전용 도구 6종 중 필요한 것을 선택합니다. 모든 점검 제안에는 참고한 원본 기록이 연결되어 있어, 화면에서 누르면 어떤 값을 보고 판단했는지 바로 확인할 수 있습니다. 데이터로 알 수 없는 부분도 함께 알려줍니다. 1차측과 2차측 계측을 구분하고 신고 이후 정보는 보지 않도록 하는 등, 설비 데이터를 다룰 때 헷갈리기 쉬운 부분을 도구에 반영했습니다. 공개 지역난방 데이터(PreDist v2)의 실제 신고로 만든 데모를 API 키 없이 볼 수 있습니다. Claude Sonnet 5와 같은 자료로 4건을 비교한 결과와 한계도 함께 공개합니다.

## 활용한 핵심 기술 및 AI 모델

- NVIDIA Nemotron 3 Ultra (NIM, `nvidia/nemotron-3-ultra-550b-a55b`): 에이전트의 두뇌. 도구 6종 중 필요한 것을 고르고(tool calling), 결과를 비교해 JSON 스키마 구조화 출력으로 점검안 작성. 모든 데모의 핵심 경로
- NVIDIA NeMo Agent Toolkit 1.8.0: 읽기 도구 6종 등록·실행. 직접 호출과 동등성 확인, 사례 52 개발 실행에서 6회 조회 실행 (계획 루프는 자체 Python 코드)
- NVIDIA OpenShell 0.1.2: 허용 읽기만 통과, 쓰기·비허용 읽기·직접 TCP 차단을 별도 시험 (전체 경로 미적용)
- 계획: Nemotron Nano 상시 감시·재정렬, NeMo Retriever 문서·도면 검색
- 기타: Python 3.12+, uv, unittest, HTML/CSS/JS; 비교 대상 Claude Code + `claude-sonnet-5`; 공개 자료 PreDist v2 (CC BY 4.0), DOE 공개 증기 계통도
