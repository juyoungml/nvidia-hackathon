    초기 4건 비교 (이전 결과)

    같은 자료로 Ultra는 2건, Claude Sonnet 5는 4건에서 근거가 제대로 연결된 점검안을 냈습니다. 그중 개발 중 한 번도 보지 않은 설비 2건에서는 Ultra 1건, Sonnet 2건입니다. Ultra가 놓친 2건은 정해 둔 조회 횟수(6번)를 다 쓰고도 조사를 마무리하지 못한 경우였습니다.

    사례 52 수정

    조회 한도에 닿으면 그때까지 모은 자료로 정리하도록 바꿨습니다. 사례 52는 이 수정을 적용해 다시 돌린 결과이고, 위 비교 점수에는 넣지 않았습니다.

    남은 과제

    근거 연결 검사는 제안이 실제 기록을 가리키는지만 봅니다. 문장 내용이 맞는지는 사람이 확인해야 합니다. 현장 전문가 평가와 실제 조사 시간 단축은 다음 단계에서 측정합니다.

    현재 기준 결과는 사건 32건 평가입니다. Claude Sonnet 5는 32건 모두, Nemotron 3 Ultra는 API 오류로 멈춘 건을 다시 실행한 뒤 26건을 통과했습니다. 남은 실패 6건은 모두 같은 도구 사용 실수였고, 이를 고친 뒤 다시 평가하고 있습니다. 소개 페이지의 평가 결과 보기 ↗

    표시된 실행 시간은 모델과 도구가 동작한 시간입니다. 현장 문제 해결에 걸린 시간이 아닙니다.
