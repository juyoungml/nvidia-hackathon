# 제출 준비도 평가

2026-09-28. 사전에 고정한 [평가 기준 v1](RUBRIC.md)으로 별도 AI 검토자 두 명이 평가했다. 공식 배점이나 실제 심사 결과 예측이 아니다. 점수 목표에 맞춰 배점·통과 조건을 변경하지 않았다.

**보수 합산 86/100. 모든 영역이 18점을 넘지만, 최종 화면 검수가 남아 전체 통과는 아직 선언하지 않는다.**

| 공고 기반 영역 | 검토 A | 검토 B | 채택한 낮은 점수 |
|---|---:|---:|---:|
| NVIDIA Agent 기술 활용 심도 | 25/25 | 25/25 | 25/25 |
| 실용성·산업가치·혁신성 | 21/25 | 19/25 | 19/25 |
| 완성도 | 22/25 | 22/25 | 22/25 |
| 커스터마이징·독창성 | 21/25 | 20/25 | 20/25 |
| **합계** | **89/100** | **86/100** | **86/100** |

항목별 근거와 감점은 [검토 A](JUDGE_A.md), [검토 B](JUDGE_B.md)에 있다. 검토 파일에 기록된 ZIP 해시는 해당 검토 시점의 스냅샷이며, 문서 갱신 후 최종 ZIP 해시는 패키지 밖의 release receipt를 따른다. 두 검토자는 실제 대회 심사위원이나 검증된 현장 전문가가 아니다. A의 산업 가치 측정 계획 평가는 B보다 높았으므로 낮은 점수를 채택했다. 최초 개선 전 평가는 별도 저자 진단이며 이 최종 두 검토자 점수와 공식적인 전후 성과로 비교하지 않는다.

## 확인된 제출물

- 코드: 실제 Nemotron 계획·공개 읽기·구조화 생성, 종료 예산 처리, 원본 사실 연결과 검수 경고. NAT 1.8.0 경유 6개 읽기 도구의 동등성과 실제 모델 선택 실행을 확인했다.
- 랜딩·데모: 실제 사례 29의 144개 계측을 그린 그래프, 원본 값·필드·시각·출처 탐색, 모델 점검 이유, 사후 검수 경고. 사례 52는 별도 개발 실행으로 표시한다.
- 슬라이드: 9장 편집 가능한 PPTX, 실제 공개 자료, native 아키텍처와 발표 노트. 최종 파일과 9장 렌더·검증 기록의 해시를 맞췄다.
- 패키지: 명시한 공개 파일만 포함하는 ZIP, 파일별 SHA-256 manifest, 비밀 패턴·개인 경로·링크 검사, 깨끗한 압축 해제 후 서버·회귀 실행을 확인했다.

## 필수 조건

| 조건 | 현재 판단 |
|---|---|
| 비밀키·회사/고객 자료 제외 | 통과. 공개 자료만 포함하며 패키지 비밀 패턴·개인 경로 검사 수행 |
| 미검증 성능·시간 단축·예방·전체 보안 주장 금지 | 통과. 현재 기능·별도 시험·향후 계획을 구분 |
| 재생과 실제 API 실행 구분 | 통과. 웹은 저장 실행이며 live CLI는 별도 |
| clean extract·주요 링크·회귀·전체 슬라이드 검수 | 실행 검사는 통과. 평가 문서 갱신 후 동일 검사를 다시 수행하여 최종 ZIP에 반영 |
| 마지막 랜딩·데모의 데스크톱/모바일 시각 검수 | **대기.** 초기 화면 검수 뒤 수정한 그래프·경고·아키텍처를 최종 브라우저에서 확인해야 함 |
| 실패와 인용 누락 공개 | 통과. 원래 2/4 대 4/4와 내용 검수 오류를 보존 |
| 현재 사건의 사후 정보 입력 차단 | 통과. 모델 입력·로컬 데모에 사후 정답을 제공하지 않음. 초기 공개 사건 3건의 사후 자료는 과거 평가 시험용으로만 ZIP의 별도 evaluation 경로에 존재하며 서버는 제공하지 않음 |

Root가 사용하던 브라우저 탭은 오류 문서의 URL 정책에 막혔고, 후속 상태 조회에서 Mac 잠금이 확인됐다. 우회하지 않았다. 사용자에게 정상 HTTP 페이지를 직접 열어두도록 요청했으며 최종 화면 검수는 아직 완료하지 않았다. 상세 실행 범위는 [QA.md](QA.md), [WEB_QA.md](WEB_QA.md)에 기록한다.

## 남은 기술·가치 검증

준비도 86점은 모델 성능 86%가 아니다. 최초 고정 비교의 출력·참조 검사 결과는 Ultra 2/4, Sonnet 4/4다. 성공한 두 사건의 익명 AI 내용 평가에서는 Ultra 41/48, Sonnet 42/48이며 양쪽 모두 6개 점검 중 3개에서 중요한 인용 누락이 발견됐다. 작은 차이를 우위로 해석하지 않는다.

현장 전문가의 점검 유용성 검토, 실제 작업 시간 절감, 같은 모델에서 구성 요소를 제거한 생성 품질 비교는 남아 있다. 8시간→30분, 24시간 예방과 발전소 실증은 성과로 주장하지 않는다.

팀명·2~5인 자격·개인별 신청과 개인정보 동의는 사용자가 마무리할 행정 조건이다. 임시명으로 파일을 준비했으며 실제 신청 완료를 뜻하지 않는다. 목표는 최종 화면 검수까지 진행 중이다.
