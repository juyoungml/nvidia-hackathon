# 제출 준비도 평가 기준 v1

고정: 2026-09-28, 제출물 개선 전. 공고의 네 항목을 각 25점으로 가정한다. 공식 배점이나 실제 심사 점수 예측이 아닌 내부 제출 준비도 기준이다. 목표는 85/100 이상이며 각 영역 최소 18/25, 모든 필수 조건 통과를 함께 요구한다. 평가를 통과시키기 위해 배점·기준을 완화하지 않는다. 변경이 필요하면 새 버전과 이유를 남기고 원래 기준 평가도 보존한다.

각 세부 항목은 0점(없음/주장뿐), 절반(부분 구현·제한된 증거), 만점(아래 증거 충족)을 기준으로 정수 채점한다. 중간 점수는 충족/미충족 내용을 명시한다. 고정 기준과 증거를 제공한 별도 검토자 2명이 평가하며, 영역별 더 낮은 점수를 채택한다. AI 검토는 현장 전문가 검증을 대체하지 않는다.

## 1. NVIDIA Agent 기술 활용 심도 — 25

| 항목 | 배점 | 만점의 증거 |
|---|---:|---|

| N2 Agent Toolkit 통합 | 6 | 최신 조사 경로의 실제 도구 실행에 NAT가 참여하며 반환값 동등성·추적·실행 증거가 있음. 별도 고정 재생만 있으면 최대 3점 |
| N3 데이터·실행 경계 | 6 | 회사 자료·키 제외, 사건 이후 정보 차단, 읽기 전용·한도·경로 검증 시험. OpenShell의 별도 시험과 전체 경로 보호 주장을 구분 |
| N4 역할과 관찰 가능성 | 5 | 구현과 계획을 구분한 아키텍처, 모델·도구·출처·실패·시각·사용량 기록. 쓰지 않는 Nano/Retriever를 통합했다고 주장하지 않음 |

## 필수 통과 조건

- 비밀키·회사/고객 원자료를 제출하지 않는다. 도구는 공개 데이터만 읽는다.
- 비교 우위·진단 정확도·8시간→30분·24시간 예방·전체 보안 통합을 미검증 성과로 제시하지 않는다.
- 핵심 데모가 재생이라는 점과 실제 live 실행 경로를 명확히 구분한다.
- 제출 ZIP의 clean extract 실행, 주요 링크, 전체 슬라이드 시각 검수, 회귀 검사가 통과한다.
- 실행 실패와 근거 검수 경고를 숨기지 않는다. 모델 출력의 사실성 오류를 성공 사례로 포장하지 않는다.
- 자료에 알려진 정답/사후 조치를 모델 입력으로 넣지 않는다. 개발·새 시험·사후 수정 결과를 구분한다.

팀명·인원·개인정보 동의·개인별 폼 제출은 사용자에게 남은 행정 조건이다. 임시명으로 패키지를 완성할 수 있지만 실제 신청 완료라고 표현하지 않는다.
